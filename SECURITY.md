# Security Policy

TotemOps v0.1.x is an experimental developer preview, not a security boundary for unrestricted agent shell access.

Use the repository's GitHub Security → Report a vulnerability option for confidential reports when available. Do not post exploit details, API keys, private player data, private mods, or production logs in public issues. If private reporting is unavailable, first request a confidential reporting channel.

Plugin capability labels are descriptive, not OS-enforced permissions. Never provide unknown plugins or weak models direct access to host Docker sockets, administrator credentials or writable production worlds. Use a separate, disposable sandbox.

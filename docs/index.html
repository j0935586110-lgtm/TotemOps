HOW IT WORKS

先找問題，再決定要不要修

不需要把正式世界交給 AI。你可以只請它分析日誌，等有需要且你同意，才在隔離沙箱測試。

  1. ① 看線索
    讀取日誌、模組檔案和目前版本。
  2. ② 查相依
    比對已知前置模組及版本限制。
  3. ③ 沙箱試修（可選）
    在獨立測試環境驗證，不修改正式玩家世界。
  4. ④ 告訴你結果
    交付有證據的報告；正式修改由服主決定。

不是什麼神奇黑盒子

它把 Python 分析、模組資料、已知版本資訊、可選 AI 和既有 Minecraft 工具串在一起。AI 負責解釋，檔案驗證和測試結果要靠工具確認。

你不必換掉原有的 Minecraft 啟動器、同步器或管理面板；也不必先申請付費 AI 帳號才能跑基本分析。

REAL TEST

真的測過的一個案例

Waystones 無法開服 → 發現缺少 Balm

注意：這證明該次伺服器能回應協定，不代表玩家登入、傳送功能或所有模組都已通過測試。其餘五類是合成日誌辨識測試，不是五次真實修復。

GET STARTED

先用最簡單的方法試試

適合會開終端機的服主或開發者。基本唯讀功能不用 Docker、Java 遊戲伺服器或 AI API Key；需要 Python 3.11+。

① 取得原始碼

git clone https://github.com/j0935586110-lgtm/TotemOps.git

從 GitHub 取得開源 Alpha 版。

② 準備 Python

cd TotemOps python3 -m pip install -r requirements.txt

Windows 可以使用 py -3 代替 python3。

③ 分析錯誤日誌

python3 tools/totem_operator.py quick diagnose latest.log

把 latest.log 改成你自己的日誌路徑，分析不會修改伺服器。

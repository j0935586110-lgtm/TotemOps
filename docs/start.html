TotemOps doesn't replace Proxmox, Docker or your Minecraft updater. Let Claude Code, AGY or OpenCode run a small CLI, read bounded JSON evidence, and decide whether a repair is warranted.

只要三個核心指令Three core CLI commands

只有執行得到的證據才算數，不能把模型的推測當成驗收。Only observed tool output is evidence. An LLM's guess is not a test receipt.

01 / MANIFEST

發布前檢查Pre-publish checks

掃 JAR 的 SHA-256、modId、宣告依賴、壞包與重複 ID；壓縮成簡短 JSON。不能憑 TOML 猜模組的完整 Client／Server 適用性。

Read JAR hashes, mod IDs, declared dependencies, bad ZIPs and collisions. Keep execution-side classification unknown until verified.

./bin/totem-ops manifest ./mods --json --summary
02 / CRASH

錯誤日誌診斷Crash triage

本地提取重點，不會把整份 latest.log 丟給模型或自動上傳到第三方。根因仍需重現驗證。

Extract bounded hints locally, without uploading or pasting the entire log into a model. Root causes remain hypotheses.

./bin/totem-ops crash ./latest.log --json
03 / SMOKE

沙箱開服驗證Isolated server smoke

僅檢查已存在、已授權且正在執行的隔離 Docker NeoForge 伺服器。不是自動部署、玩家登入或玩法保證。

Read-only inspection of an existing, authorized disposable NeoForge Docker server. Not deployment or gameplay proof.

./bin/totem-ops smoke --help

體檢、裁決、匯出：三個新指令Inspect, decide, export: three newer commands

都在本機離線跑，不開遊戲、不上傳。綠燈只代表「宣告的資料互相對得上」，不代表伺服器一定開得起來。All of these run offline on your machine. A green result only means the declared metadata agrees with itself, not that the server will boot.

04 / CLOSURE

依賴閉包Dependency closure

讀 JAR 裡宣告的依賴，算出還缺哪個前置、被誰要求、版本範圍對不對；看不懂的版本寫法會標成待確認，不會硬猜。

Read declared dependencies inside the JARs: what prerequisite is missing, who requires it, whether the version range fits. Unreadable range syntax is flagged instead of guessed.

./bin/totem-ops closure ./mods --json
05 / TRIAGE

一個裁決One verdict

把「依賴有沒有缺」和「日誌處方」合成一份結論，最嚴重的排最前面；其中一項通過不會蓋掉另一項。沒給日誌就不會假裝分析過日誌。

Merges dependency findings and log prescriptions into one verdict, worst first. One passing check never hides a failing one, and without a log it never pretends to have read one.

./bin/totem-ops triage ./mods --log ./latest.log --json
06 / PACKINDEX

匯出整合包索引Export a pack index

算出每個 JAR 的指紋並寫成 Modrinth 格式清單；只有每個檔案都有明確 HTTPS 下載來源時才寫出 .mrpack，缺一個就不寫。

Hash every JAR into a Modrinth-style index. A .mrpack is written only when every file has an explicit HTTPS download source; one missing source means no file.

./bin/totem-ops packindex ./mods --name MyPack --version 1.0.0 --minecraft 1.21.1 --loader neoforge

JSON 回報與發布守門規則JSON and release boundaries

{
  "schema": 1,
  "status": "REVIEW_REQUIRED",
  "files_analyzed": 80,
  "findings_count": 0,
  "release_allowed": false,
  "full_report_sha256": "…"
}

上方為精簡輸出示意，非實際正式伺服器收據。BLOCK (退出碼 2) 代表已知攔截；REVIEW_REQUIRED (退出碼 3) 代表不自動放行。沒有「自動批准發布」指令。

Illustrative compact output, not a production test receipt. BLOCK (exit 2) blocks known issues; REVIEW_REQUIRED (exit 3) requires review. No auto-publish command exists.
